# Furniture EPR Angular

پنل وب فارسی و راست‌چین سامانه Furniture EPR با Angular و Angular Material.

## اجرا

```bash
npm install
npm start
```

برای ساخت نسخهٔ قابل انتشار:

```bash
npm run build
```

آدرس API در فایل‌های `src/environments` تنظیم می‌شود.

## بخش‌های پیاده‌سازی‌شده در فرانت‌اند

- داشبورد اولیه
- ثبت و فهرست سفارش‌ها و مشاهده جزئیات سفارش
- فهرست کارهای تولید و عملیات مرحله، کنترل کیفیت و پایان فرآیند
- مدیریت مشتریان
- تعاریف اطلاعات پایه: دسته‌بندی‌ها، محصولات، اجزای محصول و تعداد پیش‌فرض اجزا
- مدیریت فرآیند تولید: ایجاد فرآیند و نسخه، تعریف مراحل، نقش مسئول، کنترل کیفیت، مسیرها و انتشار/اتصال به دسته‌بندی
- مدیریت کاربران، نقش‌ها و دسترسی‌ها
- پوسته واکنش‌گرا با منوی قابل جمع‌شدن در موبایل

## قرارداد ساختار کامپوننت‌ها

برای کامپوننت‌های صفحه‌ای، کد به سه فایل جدا تقسیم می‌شود:

- `*.component.ts`: منطق صفحه، فرم‌ها، سرویس‌ها و مدیریت رویدادها
- `*.component.html`: ساختار و نمایش HTML
- `*.component.scss`: استایل‌های مختص همان کامپوننت

هنگام افزودن صفحهٔ جدید، از `template` و `styles` درون‌خطی برای صفحات معمول استفاده نکنید؛ به‌جای آن `templateUrl` و `styleUrl` را به فایل‌های مجزا متصل کنید. این جداسازی نگهداری و بازبینی تغییرات را ساده‌تر می‌کند.

## ساختار

- `src/app/core`: احراز هویت، guardها و پوستهٔ اصلی
- `src/app/features`: صفحات و قابلیت‌های کسب‌وکار؛ قالب HTML و SCSS صفحات اصلی در فایل‌های جدا نگهداری می‌شوند
- `src/environments`: تنظیمات محیط و آدرس API

## نکات مهم

- صفحه‌های `/products` و `/categories` مستقیماً تب مربوط به خود را در تعاریف اطلاعات پایه باز می‌کنند.
- کنترل دسترسی رابط کاربری جایگزین کنترل دسترسی سمت API نیست.
- مسیرهای API باید با نسخهٔ در حال اجرای بک‌اند هماهنگ باشند.
- هنوز باید پروژه در محیط توسعه با `npm install` و `npm run build` بررسی شود؛ تغییرات این شاخه در این محیط اجرا نشده‌اند.
