# Furniture EPR Angular

پنل وب سامانه Furniture EPR با Angular و Angular Material.

## اجرا

```bash
npm install
npm start
```

آدرس API در فایل‌های `src/environments` تنظیم می‌شود.

## ساختار

- `core`: احراز هویت، interceptor، guard و سرویس‌های مشترک
- `layout`: پوسته اصلی پنل
- `features`: ماژول‌های کسب‌وکار
- `shared`: کامپوننت‌ها و ابزارهای قابل استفاده مجدد

رابط کاربری فارسی و RTL است.
